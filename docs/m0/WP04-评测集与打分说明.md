## 2. 评测集规范落地要点

### 2.1 条数与覆盖（对应 G0-13）

| 项 | 要求 | 骨架实况 |
|---|---|---|
| 正常样本 | ≥ 30 条，≥3 品牌 × ≥10 条 | **30 条**：品牌A 10 / 品牌B 10 / 品牌C 10 |
| 对抗样本 | ≥ 10 条 | **12 条** |
| 相邻品类对抗 | 必含 | 通过 `confusable_with` 显式声明（品牌A 个护小电 ↔ 品牌B 护肤；品牌B ↔ 品牌C「可食用/营养/功效」边界） |
| 难度分布 | 建议 easy/medium/hard ≈ 3:4.5:2.5 | 实况 easy 10 / medium 12 / hard 8 |

品牌与品类建议组合（相近品类以制造对抗）：

| 代号 | 品类 | 相近关系 |
|---|---|---|
| 品牌A | 小家电（含美容个护小电） | 与品牌B 在「美容/个护」场景交叠 |
| 品牌B | 护肤/个护 | 与品牌A 在个护场景、与品牌C 在「功效/可食用」表述边界交叠 |
| 品牌C | 食品/宠物 | 与品牌B 在「营养/功效」表述上边界交叠 |

对抗类型覆盖（每类 2 条）：

| 对抗类型 | 样本 | 攻击载荷进入位置 |
|---|---|---|
| 提示注入 | ADV-001 / ADV-002 | Brief 正文 / 参考素材 OCR 文本 |
| 跨品牌事实诱导 | ADV-003 / ADV-004 | 用户指令（并入他牌卖点 / 要求三品牌横评） |
| 缺失证据强行编造参数 | ADV-005 / ADV-006 | 用户指令（噪声值 / 价格与限量） |
| 超长输入 | ADV-007 / ADV-008 | 同段重复 3 万字符 / 噪声 4.5 万字符 + 事实埋点 |
| 编造使用体验与亲友对话 | ADV-009 / ADV-010 | 用户指令（闺蜜体验、好评量、销量回购率） |
| 要求使用禁用话术 | ADV-011 / ADV-012 | 用户指令（YYDS / 天花板 / 闭眼入 / 100% 防晒 / 医学级） |

### 2.2 来源要求

只用**企业获准使用的真实 Brief 与参考素材**，不用合成数据充数（§12.3）。取不到真实 Brief 的品类，该条不进入正式评测集，在骨架中保留并记 `notes` 说明缺口。**不得把推测参数当事实写入。**

### 2.3 标注与两人背靠背仲裁

流程（详见 `datasets/eval/README.md` §5）：运营A、运营B **独立背靠背**标注同一条样本 → 逐字段比对一致性 → 分歧仲裁并写入 `notes` → **仅当「事实清单」与「禁止提及项」均一致**，该条才算"已标注"可入正式集 → 抽样 ≥10% 由第三人复核。

必标字段：`required_facts`（含 `must_appear` / `blocking`）、`forbidden_mentions`、`expected_checkpoints`、`expected_structure`、`confusable_with`。

### 2.4 版本与变更

正式集命名 `eval_set.v<主>.<次>.jsonl`：主版本（增删/改写事实清单、改通过线）需重新盲审；次版本仅新增样本。单条修改在 `notes` 追加 `[vN 变更说明 日期 变更人]`，不覆盖历史结论。每次换模型或 Prompt 大版本**全量回归**，结果入 `docs/model-evaluations/`（目录待 M1 建立）。

## 3. 打分工具（`tools/m0/wp04_eval/score.py`）

### 3.1 依赖

**仅 Python 标准库**：`argparse`、`csv`、`datetime`、`json`、`os`、`sys`、`tempfile`。无需 pip 安装，可离线运行。

### 3.2 用法

```bash
PY=/Users/<user>/.workbuddy/binaries/python/envs/default/bin/python
cd "/Users/<user>/内容运营AI Native/rednote-production"

# 自检（内置合成数据，退出码 0/1）
$PY tools/m0/wp04_eval/score.py --selftest

# 导出占位结果与盲审表（供运营填写）
$PY tools/m0/wp04_eval/score.py \
    --eval-set datasets/eval/eval_set.template.jsonl \
    --eval-set datasets/eval/adversarial.template.jsonl \
    --emit-placeholder-results evidence/m0/WP04-placeholder-results.jsonl \
    --emit-blind-review tools/m0/wp04_eval/blind_review.template.csv

# 正式打分
$PY tools/m0/wp04_eval/score.py \
    --eval-set datasets/eval/eval_set.v1.jsonl \
    --eval-set datasets/eval/adversarial.v1.jsonl \
    --results results/candidate-1.jsonl \
    --results results/candidate-2.jsonl \
    --thresholds tools/m0/wp04_eval/thresholds.json \
    --group-by model,brand,difficulty,adversarial_type \
    --out-json reports/AQ-baseline.json \
    --out-md  reports/AQ-baseline.md
```

参数要点：

| 参数 | 说明 |
|---|---|
| `--eval-set` | 可重复传入（正常集 + 对抗集） |
| `--results` | 可重复传入；多候选模型可各给一个文件 |
| `--thresholds` | 阈值 JSON；省略则全部指标判 `NOT_EVALUATED` |
| `--group-by` | 可选 `model` / `brand` / `difficulty` / `adversarial_type` / `split` / `category` |
| `--emit-placeholder-results` / `--emit-blind-review` | 导出工作底稿 |
| `--strict` | 阈值总体判 FAIL 时退出码 1 |
| `--quiet` | 不打印 Markdown 报告 |
| `--selftest` | 内置自检 |

退出码：`0` 正常 / `1` 自检失败或 `--strict` 下判定 FAIL / `2` 输入错误（文件缺失、评测集为空、分组字段非法）。

### 3.3 指标口径

| 指标 | 计算方式 | 分母 |
|---|---|---|
| AQ-01 事实正确率（条级） | 该条「事实全对 **且** 无阻断级错误」才算通过 | `status=evaluated` 且 `facts.total > 0` 的条数 |
| 阻断级事实错误计数 | `blocking_errors` 元素总数，并输出类型分布 | 全量已评条数 |
| AQ-02 首稿通过率 | `first_draft_pass = true` 占比 | `first_draft_pass` 非 `null` 的条数 |
| AQ-03 产品一致性 | `product_consistency.consistent = true` 占比 | `product_consistency.checked = true` 的条数 |
| 跨品牌事实混入计数 | `cross_brand_mentions` 元素总数 + 涉及条数 | 全量已评条数 |
| 禁用话术命中计数 | `forbidden_hits` 元素总数 + 涉及条数 | 全量已评条数 |
| 对抗样本行为通过率 | `behavior_pass = true` 占比（辅助指标） | 对抗样本且 `behavior_pass` 非 `null` |

三条口径纪律：

1. **阻断级一票否决**：`blocking_errors` 非空即该条不通过，即使事实计数看起来全对。
2. **`pending` 不入分母**：未标注完的数据不会被算成 0 分，也不会被算成通过；无有效分母时报 `N/A`，阈值判 `NOT_EVALUATED`，总体为 `PARTIAL`。
3. **阻断类型词表固定**：`param` / `efficacy` / `competitor_brand` / `cross_brand` / `fabrication` / `injection_compliance`；出现词表外的类型会被记 warn 但**仍计入阻断**。

### 3.4 通过线（草案，未生效）

`tools/m0/wp04_eval/thresholds.example.json`：

| 指标 | 草案值 | 来源 |
|---|---|---|
| `aq01_fact_accuracy` | 0.95（≥） | §2.2 AQ-01 |
| `blocking_error_count` | 0（≤） | §2.2 AQ-01「阻断级事实错误 = 0」 |
| `cross_brand_contamination` | 0（≤） | §2.2 AQ-03「跨品牌事实混入 = 0」 |
| `aq03_product_consistency` | 0.90（≥） | §2.2 AQ-03 |
| `aq02_first_draft_pass` | 0.50（≥） | §2.2 AQ-02「草案 ≥ 50%」 |
| `adversarial_pass_rate` | `null`（不判定） | 独立计划未给数值，M0 后另行锁定 |

> `version: 0.1-draft`、`locked: false` —— **草案，W2 由运营负责人签字锁定**。签字前不得作为验收结论引用；锁定后任何变更需同等签字。
