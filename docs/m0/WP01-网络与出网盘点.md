# WP01 · 网络与出网盘点协议

> 目标：确认「企业内网从零」条件下，模式 A（内网应用 + 受控出网调外部模型）是否可行，并产出可提交审批的白名单申请。
> 执行方：运维/产品 ｜ 配合：企业 IT/安全 ｜ 时限：W1–W2

## 1. 盘点项（逐项回填，不可留空）

| # | 项目 | 需确认内容 | 现状 |

| N2 | 服务器 | 现有可用裸机/虚拟化平台（VMware/KVM/信创云），能否提供 ≥4 台规格（见计划 §14.1） | 待回填 |

## 3. 出网白名单申请单（模板）

**申请目的**：模式 A 受控出网——仅在生成任务需要时调用获批外部模型；知识库全量、费用、审计、备份不出网。

| 域名 | 用途 | 能力 | 数据类别（最小化） | 去向供应商 | 审批状态 |
|---|---|---|---|---|---|
| 待回填（文案模型 API） | 文案生成/结构化 | TEXT_STRUCTURED | 任务必要的最小上下文片段 | | ☐ |
| 待回填（图片模型 API） | 静态图生成 | STATIC_IMAGE | 批准的产品参考素材片段 | | ☐ |
| 待回填（动态图 API） | Live 动态生成 | LIVE_MOTION | 批准素材 | | ☐ |
| 待回填（embedding API，若本地不做） | 向量化 | EMBEDDING | 仅知识片段（**建议本地做，不出网**） | | ☐ |

**申请附加说明（必须随单提交）**：
1. 出网内容由模型网关记录**摘要 + 版本 + 字段类别**，普通日志不打印正文；
2. 网关侧 `LOCAL_ONLY` 项目禁止外呼，无自动降级；
3. 代理商/中转域名须一并列入白名单，不允许"动态解析域名"；
4. 无客户端直连：浏览器不持有任何供应商密钥。

## 5. 判定规则

- N6 = 不允许任何出网 → **模式 A 不成立**，必须评估模式 B（本地模型 + GPU 采购），立即升级老大，因为排期与采购都会变。
- N5 中"用户网段可达数据库"= 严重安全缺陷，必须在 M1 之前修复（否则 M1 网络验收不通过）。
