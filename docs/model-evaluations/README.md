# 模型评测归档（`docs/model-evaluations/`）

> 本目录由《Rednote 研发执行计划 V2.0》§12.3 要求建立：
> **"每次换模型 / Prompt 大版本全量回归；结果入 `docs/model-evaluations/`。"**
> 此前该目录不存在 —— 即"计划要求了归档，但没有归档的地方"（漏项，2026-09-27 补齐）。

---

## 1. 什么必须归档

| 触发条件 | 必须产出 | 依据 |
|---|---|---|
| 更换 AI 模型（新增 / 替换 / 升级） | 一份评测报告 | §12.3 |
| Prompt 大版本变更（`prompts` 表新版本发布） | 一份评测报告 | §12.3 |
| AQ 通过线签字或变更 | 签字记录 + 评测报告 | §2.2、D1 |
| 平台规则变化导致事实口径变化 | 复测报告 | 风险 R10 |

**不归档的**：单条 case 的调试记录、临时对比、未冻结的实验结果。
本目录只放**有签字或决策价值**的评测结论。

---

## 2. 命名规范

```text
YYYY-MM-DD_<模型标识>_<评测集版本>.md
```

示例：
- `2026-10-05_qwen-max_v1.md`
- `2026-10-12_claude-sonnet_v1.md`
- `2026-10-20_prompt-大版本-2_v1.md`

同名冲突时在末尾加 `-b`、`-c`。**禁止覆盖已有报告**（评测结论是历史事实）。
